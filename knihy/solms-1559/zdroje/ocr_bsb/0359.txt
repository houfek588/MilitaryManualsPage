Von der Artoloret .
94
MIltu Büchenpuluer von einander scheiden / alfo daß du den Sal
peters als weissen hast wie vor / vnd den Schwefel den andern
weg / die Kolen den dritten weg / daßdennoch ein jeglich stuck so frisch
sei wie vor / so nim des Puluers souil du wilt / thu darinn heiffen Es
fig / der siedend set / also das der Essig das dritteil vber den Salpeter
auff gehe / ond rårdas Puluer mit einem stecken in dem Essig durch
einander / ond laß das darnach ein weil stehn / so gehn die Kolen vber
sich auff / schaum dann die Kolen ab mit einem Tuchlin / das zwis-
chen ein gablin gespant set / schut darnach den Essig inn einen zwal
lichen sack so geht der Salpeter der zergangen ist durch den fack / vnd
bleibt der Schwefel darinn / denn der Schwefel mag im Wasser nit
zergehn / noch von keiner feuchtigkeit / als der falpeterthut / derschwe
fel mag auch niterger werden / Darnach wann der ſack erfeigt / fo er
iwele den Effig / ond siede in in der massen wie mann Fisch feudet / laß
den Essig darnach kalt werden / vnd den salpeter darinn gestehn / ond
seig den kalten Effig ab / so findst du den salpeter zu zopfen / den schwe
fel foltu wol auß waffer waschen / so wirter also lauter wie vor / Aber
wilt du das best scheidwaffer in dem effig / fodu am aller besten erwec
left / machen / so thu darinn Ifponicum ond Galikenstein .
Es ist geschriben vil vnd dick daß das puluer vnnük wirt / vnnd
doch von alters wegen nicht verdorben / sonder der gebrech ist / der
Dreien stuck / falpeter / fchwefel on kolen / woeins zuuil bei dem andern
ift / vnd wie mann wissen mag welches stücks zuuilist / das wirst du
in disem hernach geschriben Capitel gar eigentlich onderweist // o stes
Het auch daruon geschriben / wie mann solchs Pulucr widerbringt /
ond gutmachen soll .
Wann dir ein Puluer onder deine hendt kompt / das zuuil salpe
ter schwefel ond koln Hat / welches stück onder den dreien zuil darinn
were / so brenne des Puluers souil als ein Welschnusß auff einem gla
den stein / ist dan des falpeters zuuil / so bleiben weiß kornlin auff dem
ftein / wer dann des schwefels zuuil / so brent er langsam allweg dar
nach / wann das Puluer verbrent / es sei dann dass der schwefel me
wol gestoffen were / feind aber der Koln zuuit / so bleiben sie so rauch
wie ein Ruffrauch mit groffer onsauberkeit / Bnd bei den Vnderschei
den verstehest du wol welchs stuck zuuil ist / oder seinkan .
wiemann verdorben Puluer wider brin
gen vnd ernewern foll .
