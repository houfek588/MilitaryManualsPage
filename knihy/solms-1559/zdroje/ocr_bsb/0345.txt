Von der Artolover .
47
Onim ein pfrimen stoß in durch das Zintloch ein / vnden auff
den boden durch das Puluer / vnnd halt das Puluer bet dir / das
man spricht / Pulueres Curafine / vin scheubes dem pfrimen nach vi
ful das zintloch damit / denn die lafy Puluerfein gar heiß und scharpff /
engindt das ander Puluer gar behendt in der Büchsen / es wer denn
verdorden / dennochhilfft im das zindt Puluer / das cs laffen muß / du
folt aber treuges Puluer auff die Buchsen ond auffs zindtloch legen /
ond wardt das du dauon kommen mögst / du solt dich auch huten /
das jmmer daffelb gut puluer off dem anzintloch ensindest an / das
wag puluer das soltu allweg enkinden / so magstu on schaden wol
von der Büchsen komen .
Wie dudich vor der Buchsenhüten solt /
ob du besorgst das sie breche .
Iltu auß einer Büchsen fchteffen gewiß fchoß / ond daß du nicht
zuhoch scheust / oder du magst kaum hinkomen / auch wiffe das
gewicht des steins / kloken vnd des Pulucrs / vnd sein Krafft / was
cs getragen mag / alfß du wol vernomen haft in difem Büch / wilt du
ficher vor der Buchfenfein / das fie dir kein schaden breng noch thu /
so stehe zwischen dem boden / vnd der feiten der Büchsen zehen schrit
weiter .
Wie du einen Thurn niderſchieſſen ſolt .
Wiltu einen Thurn ntderschieffen / so lugdaß du habst einen guten
Quadraten auff ein rechte menfur / ond ein gute Buchsen / vnd daß du
fie ladest mit güten Büchsen kliyen / den Buchsenstein soltu binden
mit güten eiseren reiffen / fie Creuswerf vbereinander gehn / lugdaß
du ein rechte mensur habst zweier mann hoch an Thurn / von dem
Erdtrich / vnd alle schoß die du thüst / die thue neben einander / vnnd
scheuß nicht höcher noch niderer / fo erschelt sich der Thurn / vnd fellet
behend nider / denn ob mann ſonſt fast schoß / vnd vil daran / vnd das
ist gewiß .
Four Kugel aufz der Buchsen schieffen /
wiltu können / so merek dise lere eben .
Wilfu
