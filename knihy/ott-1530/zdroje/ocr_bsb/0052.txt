ZeWgwart beuelch .
Itemder Zemgwart / sollallen Zemg / vnd die ganz Mundicey / in seis
nem beuelchhaben / Allesdaserins Veld fürt / soll immitainem Inuen
tari / inuentiert / überantwurtwerden / darmit der Zemgmaiſterdem
KriegsHerren anzaigen Eind / Was der Statt oder dem Schloss an
Zemg / vndannderm / aufgegangenſey / oder was im voratda ist / oder
was der ganng Veldzug / an Rugeln / Puluer / vnd anderm Uncoſten
genomen hab / fich ferrner darnach haben zurichten .
Jrem es sollim mit fleyß verzeichnet werden / sovil Rugeln / fovil Puls
uers / vnnd also durchauf / alle Mundiceybeschriben / auch alle nacht /
was denselben tag aufgeganngen ist / vndwasingedunckt / daszuwe
nig werden will / foll er dem Zergmaister in gehaim ſagen / vnd sonnst
nyemanteroffnen / Dakander Zeiügmaiſter im KriegsKatt wolmels
dungthin / das sollicher mangel erstatt werd / oder in anderweg / fich
die KriegsRatwiſſen zuhallten .
Vnd waer / der Zemgwart / von andern gefragt wurd / ob nit mangel
andem oder disemsey / Soll er fich allwegen / mit guttem troft / horen las
sen / Erbabſein noch genüg / da sey kain mangel / Darmit deſtweniger
Deyterey / gegenden Veinden gemacht werd / vnd destweniger waiche
vnder das Kriegs Volck komen müge .
Item der Zewgwart soll auch im ziehen / alle nacht die Puluerwågen
ſtellen / oderbeuelhenzustellen / auffiren verordenten Platz / wie dandas
durch die Quartiervin Zewgmaiſter anzaigt wirdt / Darnach die ans
dern Artelarey wågen / alsain Wagenpurg / darumbschliessen / Dar
umb sollen im annder Zerg Diener hilflich sein / darmit nyemande zi
dem Puluermügekomen mit Fewz / weder Veind noch Fraind / in Lers
man oder sonnst .
Er soll auch allemorgen / so die Fürlewt angespannen haben / widerum
yeden Furman erfordern / wie er faren soll / darmit er die wågen in ord
nungbehallt / Eswillſeinmasshaben / wieyeder Wagen gansoll / dars
mitman kündeainem yeden Zemg Dienersagen / Da findst du den was
gen / daden andern / Es wayftmancher Furman ſelb nit / was er fürt /
auch dernechst darhinder / was der vorder oder annderfüren / Eswår
auchnitgut / das man es allemal wiſſenſollt .
