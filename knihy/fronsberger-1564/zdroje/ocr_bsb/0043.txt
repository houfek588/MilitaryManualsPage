XVIII
Nothschlangen und dergleichen Geschuk / so man den auff Redern fortbringen / ges
winnen ond nöthen mag / ist ohn noth Scharpffmeken vnnd schwere ongebreuchli
che Stück mit zuführen / dann darauff nicht allein beschwerlicher groffer kosten / son
dern auch viel mühe / arbeyt / vnd viel verhinderung eines ganken Heerlägers volgt /
besonder so man den Feind würd suchen . Item wil sich ein Herr inn feinem Land
finden laffen / sich daselbst wehren / die sachen auff ein Schlacht sehen / so er dann mit
gutem Feldtgeschuk / als Nothschlangen / Schlangen / Falckonen / Falckonet vnnd
Orgel Gefchüß / auch Hacken auff bocken nach notturfft versehen / ist ohn noth gröf
fer und schwerer Geschüß / des jhn liederlich verhindern / vnnd zu grossem nachtheyk
kommen mag / mit zuführen / Darumb ist inn diesem fall nit maß zuseken / sondern
ſteht das dem Kriegsherren / sampt seinen Hauptleuthen / Zeugmeyster vnd Kriegss
rathen / die geschickt vnd tvnd erfahrn follen fein / nach gelegenhent vnd notturfft zu bedens
cken und zuordnen .
Es ist auch hie ohn noth zumelden die Namen / schwere vnnd grösse des Gea
[ chuk / der Kuglen aller Geschüs / dann man es an einem ort anders dann an dem ans
Dern pflegt zunennen / so wird auch schier täglich anders erdacht / aber gut vnnd von
noten ist / daß man ein güten bericht hab / wie das Geschüß mit ſampt aller anderer
Munition vnd zügehör / geordnet vnd gefürt werden soll / im Zug vi imLager / auch
den Schanken .
Item an ein Büchsen so hundert Centner wigt / die wird nicht im Gefäß / sons
dern das Rohr allein auff einem eygen Wagen geführt / darfür gehören zum wenigs
ften fechhehen Rof / alfo gebürt ohne den Wagen / der starck / defhalben auch schwer
fein mus / so achkehen Roß seind / einem jeden Pferdt sechsthalben Centner / daran
hat es / so die schwere des Wagens erwegen wird / zu Berg vnd Thal genug zu zihen /
dann man die Pferdt nicht vberladen foll / damit so es von noten ist / daß man fürder
lich fahren / von vnd zu den Feinden kommen moge .
Zü folchen vnd dergleichen Büchsen müß jeglicher sein gefäß leer vnnd ledig
hernach geführt werden / daran sekt man Pferdt / fouiel die notturfft erfordert / nach
dem das gefäß schwer oder leicht ist / mag leicht erwegen vnnd ausgerechnet werden /
was man darfür ſpannen foll .
Also werden gewönlich die Stuck so vierzig Centner vnnd darüber wegen / al
lein die Rohr auff eygen Wagen / doch etwann wo es gesein mag / zwey Rohr auff eis
nem Wagen geführt / vnd die gefäß ledig geführt .
Vnd ist zumercken das es gut / wo es mit gelegenheyt geschehen mag / daß man
die Stuck so schwer feind / ob sie schon inn gefäsen zuführen vnnd mit zubringen wes
ren / die Rohr auff Wagen / vnnd die gefäß besondern führe / omb des willen / damie
die gefäß vom führen nicht zerschutt / so man darnach darauff scheuffet / dest ehe zer
brechen .
