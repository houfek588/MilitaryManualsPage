Vnd ist erstlich ein art des Geschuß die nennt man Fewrbüchsen / das seind furs
he stück ungefährlich vier schuch lang / mit weiten roren / also daß ein rohr gar nach
bey eins schuchs weit ist / Wiewol man mags machen wie man wil / Diese fewrbüche
sen pflegt man mit ins Feldt zufären / vnd daraus fewrkugeln in die Besakungen /
oder auch inn einem Feldt vnter einem hauffen zuschieffen / darumb sie auch Fewrs
büchsen genannt werden .
Sie feind auch faft gebreuchlich inn Besakungen vmb der groffen groffen kuglen wils
len / damit in die Edger zuschieffen / vnd sonderlichen derlichen so man ftürmbt / mbt / diefelbig Diefelbigen mit
Hagel zuladen / in die streichwehren / auch vnter die lücken / on wo noch zugebrauchen /
man scheuft steynen kuglen darauß / so mans nit zum Fewrwerck braucht .
Noch ist ein ander geschlecht der Büchsen / die man Merthier oder Boler nent /
derselbigen macht man vielerley / je ein art groffer dann die ander / alfo / daß mans ets
wann macht / daß einer zwen Centner schwer steyn wirfft / etwann ein Centner / ets
wann ein halben / etwan noch kleyner / biß auff zehen pfundt schwer steyn / vnd dis ges
Schlecht des Geschüs braucht man auch vor den Besakungen / alfo / daß man Fewre
werck oder steynen Kuglen darauf wirfft / man richtet sie aber inn alle hohe / vnnd
wirfft die Kuglen in lufft / alfo / daß sie dahin gericht wird / daß sie am herabfallen inn
Die Besakung fellt / vnd das macht in einer Besakung groffen schrecken vnd vnråhe /
sonderlich wo enge Besakungen / als Heuser oder Schlösser feind / dann so man
schwere steyn darauß wirfft / fallen sie durch alle Gebew / Geweld / vnd thun mereka
lichen schaden / man führt und scheusset sie auch auff der Achi / vnd in jren besondern
gefefen / sonderlich die groffen vin schweren / aber die kleynen legt man nur schlecht auff
den boden / etwann vnterlegt mans mit fandt oder holk / nachdem der boden fest oder
luck ift / etliche nennen dis geschlecht der Büchsen Narren / vmb des willen / dieweit
fie ( wie die Narren ) mit fteynen werffen .
Noch ist auch ein geschlecht des Geschuk / das man auch auff der Achs führe
vnd scheuit / das nennt man ein Orgel Gefchük / vmb des willen / dieweil es viel rohe
vnd nachbüchsen hat / zugleich wie ein Orgel viel Pfeiffen hat / man nennts auch ein
geschrey Geschüß / der vrfach / daß es viel schüß thut / nachdem es viel rohr hat / diefelbi
gen schuß zerstrewt es hin vnnd her / so nennt mans auch Hagel Geschüs / dieweil es
viel Kuglen scheuffet / wie ein Hagel vil fteyn wirfft / es ist aber ein solche art / daß man
viel Handtrohr zusammen inn ein gefeß darzu dienstlich ordnet / gleich wie ein Ors
gel mit vielen Pfeiffen / das ist also sugericht / so mans anzundt / gehen die rohr jimmer
eins nach dem andern ab / vnd ist also geordnet / daß diefelben schuß sich in alle ort hin
vnd wider zerthenlen vin zerstrewen / vnd so mans anzundt / so wehret es ein gute weit
bisß die vor alle abgehen / vnd ist dif Geschütz sonderlich gebreuchlich inn einer Feldts
schlacht für ein ordnung / oder in einer Besakung unter ein lücken da man des sturms
wartet / zustellen / dann es thut groffen schaden in die ndhe / man machts oder scheus
Tets auch etwann von einem ftück / es ist aber schwer / vnd nicht so gebreuchlich / als so
mans mit handtrohren zusamen macht .
