Von allerhand Kriegsfrüstung vnd gebrauch /
wol versorgt vnd verwart / mit sampt ihrer zugehörung / als brücken / thillen / hondten
oder binnen / latten / sparren hölkern / auch någel / seylern vnnd ketten / dann wo man
wber waffer zeucht / so muß solche brucken grossen gewalt vnd last tragen vnnd leiden /
vom geschüs so darüber geführt wird / dergleichen von dem Reysigen Zeug und Füße
volck / auch anders mehr / fo darüber geführt / welches alles ohn noth ist omb der långe
zuerzelen .
Dieweil dan souil Schiff vonnoten / so gehört vn erfordert ein jeglich Schiff /
fampt seiner zugehörung ein eygen Wagen / vnd jegklicher Wagen zu dem wenigste
vier pferdt / ein Fürmann / vnnd allwegen zu zweyen Wägen ein handtknecht ohn die
Zimmerleuth / ohn was täglich darauff geht / darauf dann leichtlich ist abzunemen
ond zurechnen / was ein solche Schiff brück ein Monat koftet zuerhalten .
Item dieser obgemelten Schiff eins soll zum wenigsten fiben oder acht schuch
breyt / sechsehen oder achhehen lang sein / vnd ein jegliche binne oder thillen so darauff
gehort / foll sein so breyt als das Schiff ift / vnnd an der länge haben zehen oder zwölff
chuch / Die Wäge darauff man folliche Brücken fürt / feind gleich wie ander Kangs
swågen / dann daß die Kipffblock hinden vnnd vomen mit guten starcken Spauchen
oder Stüken / doch daß die hoher dann die Reder feind / vnd starck Zwerchlatten / dars
auff die Binne oder Thillen raum gnüg hat zuliegen / darnach das Schiff oben dar
auff / das foll vmbgestürkt sein / damit der rågen vnd waffer im ziehen / vnd fonft vbers
ab scheußt .
Es wer auch gut / daß man in ein Feldhug mit neme / vnnd fiärte etlich Mülen /
als Roj / Windt / zug vnd treyb / oder ander Mülwerek / dann es begibt sich viel vnnd
offt / daß etwann mangel an der Prouandt / vnd die Målen durch die Feind verbrens
net / zerrissen vnnd verderbt werden / dermassen / daß man nicht mahlen fan / oder das
waffer gefroren / vnd funft mangel daran ist . Derhalben kommen folliche Mühlen
etwann zu güten ſtatten / dann man kan solche Feldtmühlen auff eim Wagen wohl
führen / vnd darneben nichts deftminder mahlen im ziehen / führen oder still ligen / i2 .
