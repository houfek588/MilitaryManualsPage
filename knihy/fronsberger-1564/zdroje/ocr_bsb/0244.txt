Per an ein orth feinen hauffen / als ob er daselbs durchtringen woll / vnd wann das

etliche tag / vnd schick die thewreste Reysigen tag ond nacht / die verlafne Flüt vnuers
sehenlich einzunemen / cyl jhn streng nach / Oder laß die wolbekleydte Knecht wol ges

Holk vund gesteud darauff / zunds an / vnnd weich zuruck / Oder werd vmb erdichten
fried / laß nachts die Wachten vom Blasen vnnd Trommen / zeuch still in einen vors
theyl / heyß die Wächter auff den geringsten pferden angehend tags nachreitten / richt
etlich block auff knechtisch bekleydt / verlas hund / Müller / Efel vnd Ochsen angebun
