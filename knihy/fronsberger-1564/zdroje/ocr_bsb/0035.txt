So nuh der vorrath von Puluer vorhanden / foll man fehen / daß daffelbige vor
verrätherey / vnd vntrew wol verwart vnd behalten werde / dann es gehört grosse sorg
zu verwarung des Puluers / ctwann farläßigkeyt / auch verrätheren / vnd allerhande
vrsachen halben / es ist aber hoch von nöten / daß mans an vielen orten / vnd weit von
einander thue / damit / wo fich vnrath zutrüge / daß man nit auff ein mal vmb viel / os
der gar darumb komme / man pflegts fast in Thürn vnd Gewölben zubehalten / es ist
aber allein des Plik vnnd Wetters halben etwas forglich / dann es ist offt geschehen /
daß das Wetter inn einen Puluerthurn geschlagen / daruon ( dieweil derselbig ein
ſtercke und gewalt hat ) groffer schaden kommen ist . Deshalben wa es sonst mit gus
ten flatten geschehen mag / so wird es nit baf verwart / dann in einem Hauß zu oberst
onterm dach / dann so es schon vom Wetter oder sonst angehet / so wirffts nur das
Dach hinweg / vnnd ist so groffer schaden nit / als in einem vesten Thurn oder Gewölb
subesorgen / Damit man auch zum füglichsten zum Puluer kommen moge / so follen
Die Herrn felbs Puluermålen vnd Puluermacher haben / mit denen sollen fie fich wie
fie mogen zum besten in vortheyl fchicken / doch dafs es die armen Gesellen auch erleis
den mögen / vnd darbey bleiben können .
