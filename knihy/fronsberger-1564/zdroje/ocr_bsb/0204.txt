Von allerhand Kriegprüftung ond gebrauch /
keck ond vnuerzagt sein / dann sie wolten fie gewißlich in sechs oder acht tagen rettens
daß sie auch ihr fleissig wacht und auffſehen haben / wann sie daher ziehen / wolten sie
ihnen auff diesem oder jhenem Berg nachts mit fewer / oder tags mit rauch zenchen
geben / alfdann folten sie eygentlich wissen / daß ihr rettung zugegen vnnd vorhanden
were / So dann fie in der Statt hören vnd mercken würden / daß sie die feind angreifs
fen / vnd mit ihnen schlahen würden / daß sie sich dann auß der Statt machen mit jrem
zusak / vñ was wehrhaffter personen seyen / herauß ziehen / die feind zu rück angreiffen /
vnd das best thun wolten .
So dann diese Kundeschafft und verrahterey / also verfertigt / alfdann vber ets
liche tag / so verordne der Oberst das Kriegpvolck so vor der Besakung ligt / daß man
tags auff den angezeygten Berg / welcher etwann zwo oder drey meyl von dannen
ligen foll / ein groffen weitsichtigen rauch / oder bey der nacht dergleichen fewr mach
so verhoffen dann die in der Statt / es sey jhr rettung vorhanden .
Darnach etwann manche ſtund zu tag oder nacht / laß der Oberst gehlingen
im Låger ein lärmen schlahen / vnnd ein groß geschrey vnnd rumor haben / das alles
gibt den feinden ein argwohn / jhrer verhofften hälff / Darnach so es vmb mitnache
ist / so lafs der Hauptmann wider ein lärmen schlahen / im selbigen lärmen breche er
auff / ond verruck mit dem ganzen hauffen / zu Roß vnnd füß mit allem geschük / Zels
ten / vnd dem ganzen Kriegszeug / vnd ziehe ungefährlich auff ein Teutsche meyl den
Feinden auf den augen / in dem verstecke er beseis etliche hauffen / darzu dienstlich zu
Roß vn Fuß / auch etlich gering Feldgeschük / hinder Wald oder Bihel / daß die feind
so sie auf der Statt ziehen / sie nicht sehen oder mercken können / vnnd ziehe er mie
dem andern Kriegsvolck etwann weit für auf / doch nit zu weit / damit er den seis
nen / so es noth beschehe / wider zu hülff kommen möge / dann verordne er bey seinem
hauffen / daß man weidlich mit dem groffen geschuk / auch die handschaken offt vnnd
eilends abschieffen / zugleich als ob man ernstlich scharmüßelt oder jekt angriff / vnnd
sey mit seinem hauffen in der Ordnung gefasset / so dann die feind in der Statt sols
lich schiessen horen / fo vermeynen sie / es gehe an die Schlacht / vnd ziehen herauß der
meynung / den jhren zuhelffen / fo sie dann zwischen oder für die versteckte hauffen
Herauf kommen / brechen dieselbigen hinder / vnnd der Oberst mit seinem hauffen voz
den feinden an / schlahen sie / in dem kompt der hinderhalt herfür / daß sie in der fluche
nicht wider in die Statt mögen kommen / dan laß von stund an der Oberst alle straf
sen vnd zugang zur Statt berennen vnnd verhalten / damit die flüchtigen zerstrewte
feind nicht wider in die Statt kommen mögen / So dann also die Statt nicht allein
jrs zusak / sondern auch villeicht und ohn zweiffel viel jhrer besten vnnd wehrlichsten
Bürger beraubt / so ist die Statt in dem schrecken leichtlich zuerobern / Gott geb wie
vest fie auch ist .
