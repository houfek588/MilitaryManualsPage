Derselbig erfordert Kriegsman steht dann hinein in Ring / zeyge an / nachdem
er bey einem hohen pfand seinem Eydt erfordert sey / so sey er allein der sachen niche
weiß genug / bittet / daß man ihm etliche ehrlicis Kriegfleuth mit denen er sich beras
then möge / zulaß vnnd vergunne / fo das geschehen / fo rufft er / so rufft er etlichen guten gesellen /
ekwann zwen oder mehr / mit denen tritt er auf dem Ring / auff ein befonder orth / dies
felbigen entschliessen sich einer vrtheyl / dann trit der gefragt wider inn Ring / ſpriche
sein gefaßte vrtheyl offentlichen auf .
Darnach erfordert der Feldweybel aber einen andern / der thut aller ding wie
der erst gethon / das geschicht zum dritten mal / Aber doch / welcher in dem einen Rath
gewesen / der foll in dem andern vnd dritten nicht fein / vnd so alfo die drey Rath vand
vrtheyl gegeben feind / wo sie dann alle drey mit einander stimmen / so macht man im
Ring ein stille / vnd schreit ein Feldtweybel offentlich auß / vnd zeygt an / nachdem die
vrtheyl gangen / vnd alle zusammen stimmen / wo nuh deren gelebt vnd nachkommen
werden foll / welchem das gefellt der soll ein hand auff heben / So man nuh die hend
auffgehaben / vnnd wider nider gelassen / dann schreyt der Feldtweybel wider / wels
chem es nicht gefall / soll auch ein hand auffheben / darnach was das mehr ist / dabey
bleibt es .
Were aber daß die drey Rath nicht miteinander stimpten / oder zwen ſtimpten
wider den dritten / als so der erst Rath hett geurtheylt / man soll den armen Mann
mit dem Schwerdt richten / der ander Rath hett sein wrtheyl geben / man folt jhne
an ein Baum hencken / Der dritt Rath hett sein vrtheyl geben / man folt ihn durch
Die Spief jagen oder dergleichen / Alfdann was der gemeyn Mann mit dem mehr
ausspricht oder macht / das ist die vrtheyl / die an dem armen Mann volstreckt wers
den soll .
Begibt sich aber / daß er einen vbelthäter auf befelch des Obersten für Recht )
vnnd das ordenlich Gericht stellt / vnnd daselbs beklagen soll / dann wird daselbs mie
Klag ond Antwort dem ordenlichen Rechten nachgangen vand gelebt / doch soll der
Profoß den armen durch einen Fürsprechen den er vnter den Richtern nimpt / ans
klagen .
Sein Eyd vnd pflicht wird ihm nach seinem Ampt vnd Befelch der notturffe
nach gestelt / vnd durch den Obersten von ihm genommen / der jhn dann mit disem bes
felch zuuersehen hat .
Sein Besoldung ist Monats N. Gülden / jhme werden gehalten zwen Tras
banten / etwann drey vnnd vier / oder vier Steckenknecht / vnd ein Jung / darnach der
hauff groß ist / vnnd die notturfft erfordert / defgleichen ein Stockmeyster vnnd ein
