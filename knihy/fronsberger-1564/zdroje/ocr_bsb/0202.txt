Statt Ordnung vnd Belägerung .

wehlen ond nemen erfarne Kriegsleuth / Zeug vnnd Büchsenmeyster / Werck
vnd Bawmeyster / Steynmeken / Mawrer vnnd Zimmerleuth / die sollen voz
der Statt auff ein viertheyl meyl vmbher besichtigen vnd befehen / obs eben oder vns
eben / grübig / bergig / thålig / waſſerig / holkig / fumpffig oder mosig / ob brücken / weg /
fteg / baum / thilen / gemewr / heuser / oder anders dergleichen / abzubrechen / vñ ob man

kurfft / alle Basteyen vnd Bollwerck mit geschüß vnd geschoß / auch mit güten Schu

in ein Statt / fonder gehören für ein Statt vnd mawr / so dann der feind kompt vnnd
nahet / schank und Låger schlahen wil / foll man ihm mit geschüß vnnd schieffen / vnnd
Scharmügeln zugegen fein / vnd jhn verhindern an ihrem fürnemen wo man kan / So
