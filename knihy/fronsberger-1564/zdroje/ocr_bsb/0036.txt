Von allerhand Kriegsprüftung vnd gebrauch /
In einem jeden Zeughaus / besonder da besaßungen seind / ist vonnöten / daß
man ein notturfftig anzal schlecht Werckpuluer hab / Nämlich / zu den Fewe
wercken / auch damit die Sturmkrüge ( an Stürmen zuwerffen ) zufüllen / dann das
selbig puluer gut gnug darzu ist / vnd wäger dann das man deß besten schiefpuluers
( das dann viel mehr koftet ) darzu neme / vnnd so follich puluer von drey theyt Sals
peter / eym teyl Schwabel / vnd eim halben theyl koln gemacht / vn wol gearbent wird /
ist es gut gnug / darff auch nicht gefurnt sein .
Item ein Zeughaus soll auch nach notturfft / vnd nach anzal grosse oder kleine
des geschus mit allerhand groffen und kleinen ensinen Kuglen versorgt vnd versehen
fein / auch zu den gar groffen Büchsen / vnd zu den Bölern mit seinen Kuglen / die fels
bige würfft man auß den Bolern / man scheuffet sie auch etwann in einer befasung
auf den fewr vnd andern den gröften Büchsen in die Låger / so seind sie auch faft gut
zubrauchen / vnnd uit so groffes kostens wie die eysinen Kuglen / am puluer brauche
man auch nicht souiel .
Item man fol auch zum vorrath mit einer namhafften anzal guts schwabels
versorgt vnd versehen sein .
Item desgleichen mit güten Lindin / Fålbin / oder andern Kolen / so zum Puls
uer machen dienstlich .
So man dann also mit Salpeter / Schwabel / vnd Koln im vorrath ſtattlich
versehen ist / kan man allwegen bald Puluer machen .
Item zum vorrath soll vn muß man auch haben / ein gute anzal güts vñ wolbes
rents Salpeters / damit man ( fo not ) puluer machen kone . Es kompt aber ein Herz od
Potentat nicht bas zu Salpeter / dann das er sich befleißt inn seiner Landtschafft / in
allen Stätten vnd Fläcken / Salpeter sieder zu ordnen vnnd feken / den felbigen this
man etwas geringen vortheyl als mit schlechtem brennholy / Jtem das man sie frey
ses / vnnd dergleichen schlechte vortheyl / da dem Herzen gar nichts oder wenig auffs
geht / Dargegen verding man sich mit den Salpeter siedern / das sie auch den Sala
peter omb ein recht gelt geben vn laffen müffen / man ordne auch geschickte leuth dazu
die sich darauff verstehen / darob vnd daran feyen / damit die Salpeter sieder nit mås
sig gehen / vnd jhr arbeyt im fårgang sey . So man aber einen spürt / so den vortheyt
vom Herzen hette / mäß derselbig mit ernst gestrafft werden / Alfo mag ein Herz vmb
zimlichen leidlichen werth in kurzer zeit zu vil Salpeters bekorñen / der Salpeter folk
auch als dann wol auffgehaben und verwart werden .
Weiter ist auch vonnsten zuhaben / zangen vnnd model / damit man zu den ges
ringen stücken vnd Feldgefchüß / als Schlangen / Falckonen / Falekanetlin vnnd ans
dern / auch in der not so ensen Kuglen zerrinnen wolten / zu den Notſchlangen vber
eyine schrot Kuglen gießen könd / auch zu den Scharpffentinlin / Loppel ond andern
Hacken vnnd handtgeschuk Kuglen zuschiessen hab / dieweil man auch offt des bleys
zu anderer notturfft haben muß / so ist vonnöten / dz man sich mit ſtattlichem vorrach
des bleys versehe .
Item man sol auch haben / etwann manche thunnen mit hark / Bach vnd Lein
dl / das man zum fewrwerck ond anderer notturfft zugebrauchen habe .
